# Cosmic Explorer - Print Guide

## Print Specifications

### File Details

- **Design File:** cosmic-explorer-tshirt-design.png
- **Resolution:** 768x768 pixels (scalable)
- **Format:** PNG with transparency
- **Color Mode:** RGB

### Recommended Print Settings

#### Direct-to-Garment (DTG)

- **Print Size:** 10-12 inches wide
- **Placement:** Center chest, 3-4 inches below collar
- **Colors:** Full color CMYK
- **White Underbase:** Required for dark garments

#### Screen Printing

- **Colors:** 4-6 color separation recommended
- **Mesh Count:** 160-200 LPI
- **Ink Types:** Plastisol or water-based
- **Print Order:** Dark to light colors

#### Heat Transfer

- **Material:** Premium vinyl or sublimation
- **Temperature:** 350°F (175°C)
- **Pressure:** Medium
- **Time:** 15-20 seconds

### Garment Recommendations

#### Best Shirt Colors

1. **Black** - Makes cosmic elements pop
2. **Navy Blue** - Complements space theme
3. **Deep Purple** - Matches design palette
4. **Charcoal Gray** - Neutral cosmic backdrop
5. **White** - Classic contrast option

#### Fabric Types

- 100% Cotton (classic feel)
- Cotton/Poly Blend (durability)
- Tri-Blend (premium softness)
- Organic Cotton (eco-friendly)

### Quality Control

#### Pre-Print Checklist

- [ ] File resolution adequate for print size
- [ ] Colors within printable gamut
- [ ] Design centered and properly positioned
- [ ] Transparency preserved for dark garments
- [ ] Test print on sample garment

#### Post-Print Care

- Machine wash cold water
- Tumble dry low heat
- Do not iron directly on design
- Turn inside out when washing
