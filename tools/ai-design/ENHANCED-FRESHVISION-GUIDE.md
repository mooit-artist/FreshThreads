## 🔧 Setup Instructions

### 1. Basic Setup (Pollinations AI)
**No setup required!** Enhanced FreshVision works immediately with Pollinations AI.

```bash
make fresh-vision-enhanced
# Opens http://localhost:8081 with full interface
```

### 2. Galaxy.ai Setup (Optional)
For professional commercial licensing and premium quality:

1. Get API key from [galaxy.ai](https://galaxy.ai)
2. Enter API key in the interface
3. Select Galaxy.ai service
4. Generate professional-grade designs

### 3. ComfyUI Setup (Optional)
For maximum local control and privacy:

1. Install ComfyUI following your existing setup
2. Ensure `comfyui_advanced_pipeline.py` is available
3. ComfyUI service will automatically appear

## 🔍 Troubleshooting

### Common Issues

**Service Not Available**
```bash
make fresh-vision-test  # Check service status
# If Pollinations fails, try different model
# If Galaxy.ai fails, check API key
```

**Generation Fails**
- Check internet connection
- Verify prompt length (keep under 500 characters)
- Try different AI service
- Simplify design concept

**Quality Issues**
- Increase image dimensions
- Switch to higher quality service
- Enhance prompt with specific keywords
- Try different theme combinations
