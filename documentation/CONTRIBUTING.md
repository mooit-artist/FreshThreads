# Contributing to FreshTreads

Welcome! FreshTreads is a tightly integrated print-on-demand storefront with secure backend logic. While this repo is currently maintained solo, contributions are welcome through structured channels.

## 🛠 Scope

This project includes:

- Frontend storefront logic (HTML, CSS, JS)

## 🔐 Contribution Guidelines

All contributions must:

- Be submitted as Pull Requests (PRs)
- Comply with active branch protection rules
  - Linear history enforced
  - Deployments must succeed
  - Signed commits only
  - Code owners must approve

## 🧵 How to Contribute

1. Fork the repo
2. Create a feature branch from `main`
3. Commit changes with signed messages:

git commit -S -m "Your message"

4. Open a Pull Request
5. Address any feedback and resolve all conversations
6. Wait for successful deployment status before merge approval
