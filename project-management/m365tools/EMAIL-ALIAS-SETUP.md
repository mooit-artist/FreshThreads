2. Sign in with <bryan@freshthreadsllc.com>
3. Navigate to **Users** → **Active users**

### **Step 2: Add Aliases**

1. Click on **Bryan Jorgensen** (your user)
2. Go to **Mail** tab
3. Click **Manage email aliases**
4. Add each alias from the list above

### **Step 3: Configure Outlook**

1. In Outlook, go to **Settings** → **Mail** → **Compose and reply**
2. Set **Default From address** as needed
3. Configure **Send As** permissions for each alias
