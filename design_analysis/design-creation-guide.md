## 🚀 Immediate Action Plan (No API Keys Needed)

### Option 1: Canva (Recommended for Beginners)

1. **Go to:** [canva.com](https://canva.com)
2. **Search:** "T-shirt design" templates
3. **Choose:** Custom size 12" x 12" (3600 x 3600 px)

**Step-by-step for "Fresh Perspective" design:**

1. Add text: "Fresh Perspective"
2. Choose clean font: Montserrat or Helvetica
3. Add subtitle: "Fresh Success"
4. Colors: Navy (#1e3a8a) background, white text

## 🎯 Design #1: "Fresh Perspective" - Start Here!

### Text Layout:

```
FRESH
PERSPECTIVE
───────────
Fresh Success
```

### Specifications:

- **Main Text:** Bold, sans-serif, 72pt
- **Subtitle:** Light weight, 24pt
- **Colors:** Navy background OR white background with navy text
- **Position:** Center chest, 10" wide max

### Quick Creation Steps:

1. Open Canva
2. Create custom 3600x3600px design
3. Add navy background rectangle
4. Add "FRESH PERSPECTIVE" in white, bold font
5. Add thin line separator
6. Add "Fresh Success" in smaller text below
7. Export as PNG (transparent background)

## 📐 Technical Specs for All Designs

### File Requirements:

- **Size:** 12" x 12" maximum (3600 x 3600 px at 300 DPI)
- **Format:** PNG with transparent background
- **Color Mode:** RGB for screen, CMYK for print
- **File Size:** Under 10MB for web use

### Design Placement:

- **Front Center:** 10" x 12" max
- **Front Left Chest:** 3" x 3" max (logo version)
- **Back:** 11" x 13" max
